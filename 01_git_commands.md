# Git — основные команды

## Ежедневный рабочий процесс

| Команда | Что делает |
|---|---|
| `git status` | Показать, что изменилось |
| `git add .` | Добавить все изменения в «отправку» |
| `git commit -m "..."` | Зафиксировать с сообщением |
| `git push` | Отправить на GitHub |

## Первоначальная настройка (один раз)

| Команда | Что делает |
|---|---|
| `git config --global user.name "Имя"` | Установить имя |
| `git config --global user.email "email"` | Установить email |
| `git init` | Инициализировать репозиторий в папке |
| `git remote add origin URL` | Связать с GitHub |

## Проверка

| Команда | Что делает |
|---|---|
| `git --version` | Версия Git |
| `git remote -v` | Показать связь с GitHub |
| `git log --oneline` | История коммитов |
| `git config --global --list` | Показать настройки |
